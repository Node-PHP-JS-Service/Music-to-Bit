## 音楽ファイルをmicro:bitで再生！

MP3などの音楽ファイルを、micro:bitで再生できるプログラムコードに変換するツールです！

音声ファイルをブラウザ上で解析し、周波数や音量のデータに変換します。生成されたコードをMakeCodeに読み込めば、micro:bitのAボタンを押して音楽を再生できます！

### 特徴
- ブラウザ内で音声を解析
- 音声を周波数・音量データに変換
- micro:bit用のプログラムコードを自動生成
- Aボタンで音楽を再生
- サーバーに音声ファイルをアップロードせずに処理

### 使い方
1. 音楽ファイルを読み込む
2. 変換設定を行う
3. プログラムコードを生成する
4. MakeCodeにコードを読み込む
5. micro:bitに書き込む
6. Aボタンを押して再生！
